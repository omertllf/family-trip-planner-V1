While I'm between roles, I'm building.

Job searching takes time — but so does family. So I combined both.

I built **Family Trip Planner**: a personal side project I actually use to organize my family's upcoming summer trip. What started as a simple spreadsheet replacement turned into a full-featured web app.

**What it does:**
- Tracks flights, stays, car rentals, and activities in one place — with live cost totals per category
- **3 views**: sortable table, monthly calendar, and a Gantt timeline to spot gaps and overlaps instantly
- **AI-powered Gmail import** — paste a booking label and Claude extracts structured data from your confirmation emails
- Auto-detects duplicate bookings and flags them
- Live currency conversion (USD / EUR / ILS)
- Syncs in real-time across devices via Firebase

**Tech stack:**
- React (single-file PWA)
- Firebase Firestore for real-time sync
- Claude AI API for booking email parsing
- Deployed on GitHub Pages

**Architecture decisions I'm proud of:**
Single-file PWA keeps deployment dead simple — no build pipeline headaches, no server to maintain. Firebase handles the sync layer so the app is always live and consistent across family members' devices. AI does the tedious data-entry work.

Is it perfect? No. But it solves a real problem I had, and I learned a lot building it.
